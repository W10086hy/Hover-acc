# P3 Position 机体系零偏与质心辨识

用户已批准物理参数辨识方案，并明确允许 Position 模式、机体系学习。

P2 Actor、Adam、35 维机载输入以及历史结果冻结。P3 的新模型学习机体系三轴加速度计加性零偏 b 和水平质心偏移 r=(rx,ry,0)，不依赖高度、绳长或 Actor。r 定义为几何中心指向真实质心，单位 m。垂向质心在平行旋翼推力下不可观测，明确报告为未辨识。

Position 阶段可使用同步位置、姿态、IMU、实测 RPM、实际执行油门。位置与 IMU 应指同一已知参考点；局部位置二次拟合得到参考比力，转至 FRD 机体系后估计 b。姿态从 FRD 到 NED。位置重置、掉点和模式边界不得跨越。离线拟合允许非因果窗口；控制阶段只读取冻结校准和机载量。

角动量方程为 J*alpha + omega×(J*omega) = tau_nominal - r×F_rotor。训练可联合拟合三轴主惯量作为干扰参数，禁止用加速度计零偏代替真实力矩。受控采集关闭绳载荷及风；有变化外载的记录必须显式拒绝物理参数拟合。必须检查激励、矩阵秩、参数边界与残差，禁止将无法辨识的值作为有效校准。

补偿顺序：校正原始 IMU 的 b，再按辨识 r 和因果 gyro 差分将 IMU 从几何原点运输到 CG，随后形成 P2 历史。用 Position 数据辅助拟合质量，切换后以 `F_ng=m_identified*f_CG` 估计全部非重力合力，向分配器加入 `+r×F_ng`，角运动预测同步扣除相应运输力矩。已有预飞加速度校准不得重复扣减。CG 以实际 MuJoCo 惯性中心实现，旋翼／机体阻力几何作用中心保持 O，原生柔绳挂点不随 CG 平移。

细化依据：首轮只补偿旋翼力的 24 条配对中，开启后 12/12 安全稳态，但弱风 0/6、强风 4/6 RMSE 达标；同种子标准机体 4/4 达标。CG 改变挂点相对力臂，完整机体参考点运输才能对齐 P2 标准机体。该细化保持 P2、目标及机载输入维度冻结，新增辅助质量仅由 Position 数据辨识，不读仿真实际质量。
