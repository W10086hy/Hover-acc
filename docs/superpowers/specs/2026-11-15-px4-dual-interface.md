# PX4 双输出接口与虚拟机配对验证

用户要求新增直接向 PX4 发布加速度的独立脚本和一键入口，现有路线保留，两者在现有 Linux 虚拟机验证。本轮不更新 P2/P3 权重或 Adam，不覆盖已有仿真。

新增 NX/Python 推理与发送入口，明确区分加速度设定值和旧角速度／推力设定值。加速度方案仅发送水平加速度、切换时锁存的高度和航向，由 PX4 执行高度与姿态／角速度控制；原入口继续可用。MAVROS 支持需按虚拟机现有 ROS 环境决定具体启动方式，MAVLink 发送共用同一字段、坐标和掩码定义。

P3 观测校正可复用；纯加速度消息不能携带力矩／逐电机分配补偿。不同补偿覆盖要在配置和报告明确，不将部分 P3 校正称为完整 P3 迁移。既有原生完整 P3 证据及源码保持独立。

验证采用真实虚拟机 PX4 SITL、MuJoCo 原生柔绳，记录固件／权重／源码哈希、实际线缆消息和控制权、完整时域及失败计罚。先单例短程确认接口，再同风向／种子／机体进行 1／5 m/s、120 s 配对。PX4 Position 使用的定位输入和 Actor 禁止定位输入分开标注；GNSS 拒止时 PX4 模式有效性限制明确报告。新结果单独保存，正式最终种子不用。

沿用用户对后台虚拟机操作的授权；登录秘密只用于内存认证，不进入项目、脚本、日志或版本库。虚拟机已安装依赖优先复用，不修改系统设置或其他任务目录。
