## 沿用的风定义

纯时变风：基础风速乘以1+0.2sin(2πt/30)，平均风向加30°sin(2πt/45)。组合风再叠加每20秒一次、持续4秒、最高20%基础风速的平滑脉冲，以及时间常数1.5秒的OU湍流，标准差为基础风速的水平各10%、垂向4%。前2秒无风、2–4秒建立。基础5m/s不代表峰值5m/s；实测峰值逐工况列在CSV。

两种定义来自现有WindField；弱风应用同一公式是本次新增覆盖，历史弱风未单独验证此类阵风。没有改变为峰值裁剪风，也不是8m移动小车分支的归一化风。当前目标高度5m、EA49N、12段有质量柔绳，5/10cm挂点绳长4.90/4.85m。种子标称20681101/02、轻机体20681121/22，CPU随机初始化与此前Actor37恒风验证的完整86维初态逐值相同。

持续变风会产生受迫运动。末30秒摆动、速度、漂移仍按原始定义报告，但不把恒风的静态稳态阈值作为本次是否能抗时变风的唯一结论。安全、误差、姿态方向和风变化响应分别报告，不因误差降低自动启动训练。尚未使用保留最终种子进行正式验收。

## 倾斜抗风与完整回放

姿态曲线来自实际仿真四元数。迎风倾斜分量按推力水平向量投影到气流反方向定义，正值表示推力迎风；机头无需跟随风转向，绳张力也参与平衡。16条强风中，风建立后（4–120秒）推力迎风的时间比例最低为96.7%，末30秒最低96.3%。这表明策略在多数时段形成了正确方向的抗风倾斜，但快速风扰下仍有短暂反向与位置起伏，不能称为无瞬态误差。逐工况姿态方向比例、倾角及稳定偏置见[完整CSV](statistics.csv)。

全部工况最大实际航向误差0.865°。强风最差水平RMSE为1.207705m；弱风最差0.554046m，两条标称机体弱风结果超过0.53m工程尺度。因此不宣称旧的弱风名义0.5m目标已经逐条通过。保持本次仅测试的范围，不自动启动训练。
