## 已修复的重要问题

1. 初版全空间线性隐式K/D在近松弛时产生隐含压缩：实际段冲量反推最低−0.122299N，而载荷函数报告零。已改为非负张力互补问题，以同一Cᵀ施加所有实际段冲量，并加入独立动量反推回归测试。
2. 互补问题只执行4轮active-set不足：12段样本第175组残差−0.042682m/s，漏掉应有0.151185N的段张力。已改为N+2轮，并加入256组独立节点速度的残差检查。

## 最终只读复核

- 无剩余Critical/Important/Minor。
- 5120组CPU随机样本，覆盖float32/float64、3/12/24/64段，位置扰动0–0.2m、速度扰动0.15–5m/s；实际张力非负、状态有限。最大互补残差float64=3.56e−15、float32=2.87e−6。
- 广义映射、端点反力与r×RᵀF符号一致；节点总质量守恒，分布空气阻力随节点代表绳长缩放。
- 绳节点持续参与飞行梯度和快照/恢复/重算，Actor仍只有35维机载输入。
- 动态绳不使用旧“目标位置+原节点”的非物理反事实平衡项，保留实际轨迹的位置、航向和收敛损失。
- 资格入口30/10/1确为3000步/1000步信用/100步重算；gradient-only无附加回放、无optimizer。
- seen按重算前step号去重，预计301帧（初始帧+10Hz完整30秒）。
- 父文件整文件SHA覆盖Actor和Adam；运行Actor逐张量比对；源码预先归档并于结束核验。
