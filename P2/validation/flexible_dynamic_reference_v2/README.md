# 柔绳短时独立动态参考

这是0.3秒规定端点运动的数值台架，不是飞行、训练或实测标定。未使用MuJoCo，未创建优化器或改Actor/Adam。

固定与30秒梯度资格相同的12段材料/质量参数；两连接点5/10cm，风为0/5m/s恒风。端点x=0.12(1−cos(4πt))m，y=0，z=−5+连接点力臂m。独立NumPy绳力+SciPy Radau连续ODE，与生产隐式张力积分比较。

| 最大误差（四工况） | 2ms | 1ms | 0.5ms |
| --- | ---: | ---: | ---: |
| 自由节点位置 | 1.486mm | 0.744mm | 0.372mm |
| 即时端点力 | 0.1292N | 0.0640N | 0.0319N |

同一步实际端点力冲量与Radau区间平均力积分比较：2ms最大冲量差2.1622e−5Ns；不能把即时力误差与实际冲量误差混为一谈。历史统计保留在 result.json。

步长减半后误差约减半，支持约一阶收敛。独立只读复核进一步将Radau收紧至rtol1e−9/atol1e−11/max_step0.5ms，四工况参考最大变化仅节点1.79e−10m、端力3.21e−8N，远小于生产积分误差。


参考独立性限定为绳力公式与时间积分。初始节点取自生产模型静力解；质量在复核时独立按线密度与分段长度重算。该台架固定飞机端点，不验证自由飞机双向耦合，也不证明材料参数符合实绳，更不能解释全部旧MuJoCo失败。

复核无Critical/Important；Minor为上述独立性范围已明确。两项手算fixture与全工程81项测试通过。frozen_source.zip、audit.json及源码SHA保留对应关系；主21次Actor/Adam和P3文件未变。

当前结果只增加物理数值证据；原30秒反传465.666秒、16/16安全的结论保持原范围，未追加120秒训练。
