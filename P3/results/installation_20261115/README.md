**姿态参考假设：**待标定 IMU 的轴相对一个独立、正确的机体系姿态参考偏转。辨识时姿态为理想仿真测量，位置噪声 0.1 mm；运行仍使用原 P2 传感器噪声。不能据此宣称仅凭同一未校准 IMU 自己输出的姿态即可分离 IMU 和电机安装角。真实 PX4／实机、独立逐电机倾角和非受控外载尚未验证；本轮为开发验证。

运行时先校正 IMU，再转入已辨识推力轴的虚拟机体，按辨识几何和执行器增益一致修正分配及前向预测。P2 仍为 35 维输入和原归一化／条件参数；接管后不使用位置、风、绳真值或真实扰动参数。CG 只拟合机体水平分量，两个载荷 z 对称以使真实 CG_z=0。

各机 `calibration/calibration.pt` 含参数与 Adam，`actuator_gain.json` 为电机增益，`position.npz` 为原始采集；`flight_off`／`flight_on` 含完整轨迹、100 Hz 证据和审计；配置及采集／验证源码按 manifest 与冻结 ZIP 对应。

采集／训练源码为 `frozen_source.zip`；本次完整配对飞行源码为 `frozen_source_01.zip`。后续维护快照只增加激励／受控外载入口检查，不重写飞行来源。采集种子 2026112501／2601／2701；验证种子对 2026113501–3502／3601–3602／3701–3702，未使用正式最终保留种子。

已知次要边界：继承的 `loads` 力矩诊断仍按对角惯量重构；该返回量未进入本轮控制、辨识或评分。原生积分使用完整惯量，物理回归已单独核对。
