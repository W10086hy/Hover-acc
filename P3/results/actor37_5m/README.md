# Actor37 与新 P3 的 5 m 闭环对照

以 Actor37 及其冻结 GRU 采集 36 条 5 m 柔绳轨迹，全部安全完成。训练集种子为 20683201/02、20683211/12、20683221/22，开发集为 20683231/32，留出集为 20683241/42。RTX 3060 上完成 1000 步 Adam 拟合，耗时 4.89 秒。开发集在第 800 步达到最低损失 0.054904，零残差初值为 0.059037。P3 检查点含该步的 Adam 状态，Actor37 权重及 Adam 保持冻结。

留出集上，归一化力和力矩 MSE 从 0.08768 降至 0.02705，垂向力 RMSE 从 0.676 N 降至 0.346 N。2 ms 电机响应 RMSE 从 0.245 rad/s 升至 0.456 rad/s，合并预测损失从 0.07382 升至 0.11768。模型选择仅使用开发集。

P2 的 35 维观测含四路转子机械角速度，训练时从含一阶电机响应的仿真状态生成，加入标准差 1 rad/s 的高斯噪声、截断负值，再用标称最大转速归一化。P3 使用同一机载观测、冻结历史编码、14 维标称参数及四路电机命令。监督标签由同一物理状态下的实际与标称动力学差异生成，电机目标是实际仿真电机在该命令下 2 ms 后的转速。PX4 SITL 使用带噪仿真转速，400 Hz 采样并在 100 Hz 策略周期读取。PX4 的 P3 接口使用垂向力补偿及等效角速度偏置，P3 的电机响应输出未进入该接口。

原生 MuJoCo 使用 5/10 cm 挂点、1 m/s 恒风和 5 m/s 基础组合风，组合风实际峰值分别为 7.112 和 7.259 m/s。两种模式匹配初态与全程风场，种子 20683111/12。补偿后四个工况的水平 RMSE 均降低，合并高度 RMSE 增加约 0.106 m。PX4 使用 5 cm 挂点与 4.90 m 绳长，两种变幅风的实际峰值约为 1.00002 和 5.00009 m/s，风场种子 20683131，传感器种子 21683134。四条记录均通过完整时域、解锁与 Offboard 审计。弱风补偿后水平 RMSE 0.584 m，高于 0.53 m 工程参考线。两平台的风型与内环分别记录。本轮属于开发对照。
